Combines multiple video files into a tiled mosaic.

## Requirements
- Python >= 3.12
- Latest ffmpeg.

## Usage
- Clone this repo or download `main.py`.
- Run
  ```sh
  python main.py {directory to video files} {output file}`
  ```
  For example:
  ```sh
  python main.py "C:\Users\John\Videos\My Videos" "C:\Users\John\Videos\My Videos Mosaic.mp4"
  ```
